Student Management System – Automated Testing

Project Description:
A web-based Student Management System designed to manage student records. The application allows users to add student details, validate duplicate USNs, delete student records, and track the total number of students. Automated testing is performed using Selenium WebDriver and Pytest.

Technologies Used:

- Python
- Selenium WebDriver
- Pytest
- HTML
- CSS
- JavaScript
- Google Chrome

Test Cases:

1. Homepage loading verification
2. Adding a student record
3. Duplicate USN validation
4. Deleting a student record
5. Student count verification

Project Objective:
To automate the functional testing of a Student Management System using Selenium WebDriver and Pytest and verify that the core functionalities work correctly.
